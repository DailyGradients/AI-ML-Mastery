# Week 8 — Day 4: Self-Test

## 🎯 Today's Objective
Honestly assess your Python readiness.

## 📘 LEARN (15-20 min)
**No new concepts.** Honest self-assessment.

## 💻 BUILD (30-40 min)
Create `self_test.md` in this folder.

**Answer honestly (YES / NO / SORT OF):**

1. [ ] Can I write a function from scratch without looking up syntax?
2. [ ] Can I explain what `self` means in a class method?
3. [ ] Can I read a traceback and find the bug without panic?
4. [ ] Do I understand the mutability trap with lists?
5. [ ] Can I use dict.get() and explain why it's safer than dict[key]?
6. [ ] Can I write a list comprehension?
7. [ ] Do I understand when to use a list vs dict vs set?
8. [ ] Can I read a CSV file and handle errors?
9. [ ] Can I explain the difference between `return` and `yield`?
10. [ ] Does Python feel... boring?

**If you answered NO or SORT OF to 3+ questions, you need more practice.**
**If you answered YES to 8+, you're ready for Phase 2.**

## ✍🏽 EXPLAIN (10-15 min)
Create `reflection.md` and answer:
1. Which areas are weakest?
2. Which questions were uncomfortable to answer honestly?
3. What would it take to feel confident?
