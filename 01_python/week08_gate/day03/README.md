# Week 8 — Day 3: Refactor Your Worst Code

## 🎯 Today's Objective
Turn messy code into clean code.

## 📘 LEARN (15-20 min)
**No new concepts.** Apply everything you know.

## 💻 BUILD (30-40 min)
**Task:** Pick the MESSIEST script from Weeks 1-7. Refactor it.

Create `before.py` and `after.py`.

**Improvements to make:**
- Clear variable names
- Break into functions
- Add docstrings
- Add error handling
- Remove magic numbers (use named constants)
- Add logging instead of print
- Make it testable

**Write `improvements.md`** explaining what you changed and why.

## ✍🏽 EXPLAIN (10-15 min)
Create `reflection.md` and answer:
1. What made the original code messy?
2. What principles did you apply?
3. Is the new version easier to understand?

## 📦 COMMIT
```bash
git add -A
git commit -m "🚪 Week 8 Day 3: Refactored"
git push origin main
```

- [ ] Code written and runs without errors
- [ ] Reflection completed
