# Week 8 — Day 2: Explain ML Code

## 🎯 Today's Objective
Read scikit-learn code and understand the Python (ignore the ML).

## 📘 LEARN (15-20 min)
**Task:** Go to https://scikit-learn.org/stable/auto_examples/classification/plot_classifier_comparison.html

Copy the code example. You're going to annotate every line.

## 💻 BUILD (30-40 min)
Create `annotated_ml_code.py` in this folder.

**Task:** Take the scikit-learn example and add a comment to EVERY line explaining what the Python is doing. Ignore the ML parts.

Example:
```python
# Import the numpy library for numerical operations
import numpy as np

# This is a function definition
def make_classification(...):
    # ...
```

**Focus on:**
- What's being imported?
- What's a function call vs a class instantiation?
- What data structures are being used?
- What does each method call do?
- What's being returned?

You don't need to understand the ML. Just the Python mechanics.

## ✍🏽 EXPLAIN (10-15 min)
Create `reflection.md` and answer:
1. Could you follow the Python mechanics?
2. What Python concepts did you recognize?
3. What Python concepts confused you?
4. Do you feel ready to learn ML?
