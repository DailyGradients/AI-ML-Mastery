# Week 8 — Day 1: Build From Scratch

## 🎯 Today's Objective
Write a complete script without any references. Test your recall.

## 📘 LEARN (15-20 min)
**No learning. This is a test.**

## 💻 BUILD (30-40 min)
**Task: From a BLANK file, with no references, no Google, no looking at old code, build this:**

A script that:
1. Reads a CSV file of sales data (you'll create sample data)
2. Cleans the data (handles missing values, wrong types)
3. Calculates averages by category (column)
4. Writes the results to a new CSV file

**Rules:**
- Time yourself — aim for 45 minutes max
- NO Stack Overflow
- NO looking at old code
- NO copy-paste
- If you get stuck for 10+ minutes, write down the question and keep going

**When done, note:**
- How long did it take?
- Where did you get stuck?
- What did you have to guess?

## ✍🏽 EXPLAIN (10-15 min)
Create `reflection.md` and answer:
1. Did you finish in 45 minutes?
2. What was easy?
3. What did you have to think about?
4. Did you panic at any point?
