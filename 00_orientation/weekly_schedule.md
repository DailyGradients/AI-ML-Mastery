## Rules
- Bad day minimum: 30 minutes (NO ZERO DAYS)
- Every session starts with: what am I building today?
- Every session ends with: git add, commit, push

## Daily Session Template
1. Review objective (2 min)
2. Learn concept (15-20 min)
3. Build something (30-40 min)
4. Explain what I learned (10-15 min)
5. Git commit + push (2 min)
